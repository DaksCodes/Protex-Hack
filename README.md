# FinPocket 💰

### Your Smart Financial Companion for Gen Z

FinPocket is an end-to-end financial management platform designed to help Gen Z users build better financial habits, track expenses, gain financial insights, and plan long-term wealth growth through an intuitive and unified platform.

# 📌 Problem Statement

Despite being digitally active, many Gen Z users struggle with:

* Poor financial awareness
* Lack of budgeting habits
* Inconsistent financial decision-making
* Difficulty planning long-term wealth goals

Most existing solutions are:

* Fragmented across multiple apps
* Overly complex or generic
* Disconnected from real-life financial behavior

FinPocket aims to solve this by providing an integrated financial ecosystem with smart insights and personalized recommendations.

# ✨ Features

## 📊 Unified Dashboard

* View expenses, spending insights, and goals in one place
* Interactive charts and analytics
* Category-wise spending distribution

## 💸 Expense Tracker

* Add and manage daily expenses
* Track spending patterns
* Analyze financial habits over time

## 🤖 AI Financial Chatbot

* Personalized financial assistance
* Answers queries related to budgeting and expenses
* Smart suggestions based on user data

## 🔥 FIRE Calculator

(Financial Independence, Retire Early)

* Predicts wealth required for financial independence
* Estimates future financial goals based on spending habits

## 🧠 Smart Analytics & Recommendations

* Spending analysis
* Financial behavior insights
* AI-powered recommendations

## 📰 Financial Awareness Section

* Curated financial news and educational content
* Helps improve financial literacy
